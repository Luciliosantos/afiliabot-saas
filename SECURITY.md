# Segurança

- Nunca faça commit de `.env`.
- Nunca reutilize token de bot ou Access Token que tenha sido exposto.
- Use HTTPS.
- Use `TELEGRAM_WEBHOOK_SECRET`.
- Use `MP_WEBHOOK_SECRET`.
- Restrinja o painel administrativo.
- Faça backup do SQLite.
- Atualize PHP e sistema operacional.
- Não coloque credenciais em logs.
